### 🌐 End-to-End Azure DevOps Infrastructure Automation
**Terraform · Docker · Kubernetes · GitHub Actions · Azure DevOps**

Designed and automated Azure cloud infrastructure using Terraform (IaC) with reusable modules for Resource Groups, VNets, Subnets, NSGs, VMs, Storage Accounts, Public IPs, Load Balancers, and Application Gateways. Implemented Terraform Remote State for centralized state management, integrated `tfsec`, `TFLint`, and `Gitleaks` for security scanning, and used `Infracost` for pre-deployment cost estimation. Containerized applications with Docker and orchestrated deployments on Kubernetes (Pods, Deployments, Services, ReplicaSets, ConfigMaps, Namespaces), all wired into GitHub Actions & Azure DevOps CI/CD pipelines.
